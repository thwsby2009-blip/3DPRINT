# 🧊 AI × 全彩 3D 列印 — 產品一條龍設計

> 教學網站版｜資料來源：嚴稑榛老師課程

## 📋 課程內容

一個 Flask 教學網站，涵蓋從零到電商上架的完整流程：

| 章節 | 內容 |
|:----|:----|
| 🎯 課程概述 | 市場背景、學員成功案例 |
| 🔧 工具一覽 | Meshy.ai、ChatGPT、Gamma.app 等 |
| 🔄 一條龍流程 | 8 步驟：想法 → 3D模型 → 電商上架 |
| 💬 Prompt 技巧 | 黃金公式 + 3D 模型模板 |
| 🧊 Meshy 操作 | 6 步驟 + 台灣特色 Prompt 範本 |
| ✍️ AI 文案 | AIDA 框架 + 萬用 Prompt |
| 📊 簡報製作 | Gamma.app + 5 頁結構 |
| 🛒 電商網站 | Wix / Durable / 金流方案 |
| 💰 定價策略 | 成本分析 + 建議售價 |
| ✅ 檢查清單 | 列印前確認事項 |

## 🚀 啟動方式

```bash
cd 3d_printing_course
pip install flask
python3 app.py
```

然後開啟瀏覽器 → http://localhost:8899

## 🛠️ 技術

- Python Flask（單頁應用）
- 深色主題 RWD 設計
- 無資料庫需求，開箱即用
